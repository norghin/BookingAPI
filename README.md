# Модели данных
Booking
Id             — идентификатор заявки
ClientName     — имя клиента
ServiceType    — тип услуги
PreferredDate  — дата выполнения
Status         — статус заявки
PriceList      — список позиций прайс-листа
TotalPrice     — сумма всех позиций (вычисляется автоматически)

# BookingRequest
ClientName     — имя клиента
ServiceType    — тип услуги
PreferredDate  — дата выполнения
Status         — статус (опционально)
PriceList      — список позиций (опционально)

PriceItem
Name           — название работы или материала
Price          — стоимость

# API эндпоинты
Получить все заявки
GET /api/booking

Возвращает список всех бронирований.

Получить заявку по ID
GET /api/booking/{id}

Ответы:
200 OK — заявка найдена
404 Not Found — заявка не существует
Создать новую заявку
POST /api/booking


Проверки:
дата не может быть в прошлом
дата не может быть более чем на 1 год вперёд
на выбранную дату не должно существовать другое бронирование
у клиента не более 2 активных бронирований

Ответы:
200 OK — заявка создана
400 Bad Request — ошибка валидации
409 Conflict — превышен лимит активных бронирований или дата занята

Обновить заявку
PUT /api/booking/{id}

Позволяет:
изменить основные данные заявки
обновить статус (только допустимые значения)
заменить прайс-лист целиком

Ответы:
200 OK
404 Not Found

Добавить позицию в прайс-лист
POST /api/booking/{id}/price-item

Проверки:
название не пустое
цена больше нуля

Удалить позицию из прайс-листа
DELETE /api/booking/{id}/price-item/{index}

Удалить заявку
DELETE /api/booking/{id}

Полностью удаляет заявку.

# Сервисный слой
# BookingService

Основные методы сервиса:
GetAll()                         — получить все заявки
GetById(id)                      — получить заявку по ID
Add(request)                     — создать заявку
Update(id, request)              — обновить заявку
Remove(id)                       — удалить заявку
AddPriceItem(id, item)           — добавить позицию в прайс-лист
RemovePriceItem(id, index)       — удалить позицию из прайс-листа
IsDateTaken(date)                — проверка занятости даты
HasReachedActiveLimit(clientName)— проверка лимита активных заявок


# Вся бизнес-логика и проверки инкапсулированы в сервисе
# API возвращает корректные HTTP-статусы и текстовые сообщения
# Бизнес-ограничения обрабатываются как 409 Conflict
