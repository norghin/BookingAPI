# Описание

BookingAPI реализует CRUD-функционал для работы с бронированиями: создание, получение списка, получение конкретного бронирования, обновление статуса и удаление.  
Сервис разработан как часть микросервисной архитектуры и может интегрироваться с внешними системами (например, сервис прогноза погоды).

# Технологии

- .NET 6
- ASP.NET Web API
- Entity Framework Core
- REST API
- SwaggerUI

# Функции 

- GET /api/booking/{id}
Возвращает бронирование по ID.
- POST /api/booking
Создаёт новое бронирование.
- PUT /api/booking/{id}/status
Обновляет статус бронирования (используется администратором).
- DELETE /api/booking/{id}
Удаляет бронирование по ID.
